### Q4. Kth Smallest Element

**Problem Description**

Find the **B<sup>th</sup>** smallest element in the given array **A**.

**NOTE**: Users should try to solve it in less than or equal to B swaps.

**Problem Constraints**

```
1 <= |A| <= 100000
1 <= B <= min(|A|, 500)
1 <= A[i] <= 10^9
```

**Input Format**

The first argument is an integer array A.  
The second argument is an integer B.

**Output Format**

Return the B<sup>th</sup> smallest element in the given array.

**Example Input**

Input 1:
```
A = [2, 1, 4, 3, 2]
B = 3
```

Input 2:
```
A = [1, 2]
B = 2
```

**Example Output**

Output 1:
```
2
```

Output 2:
```
2
```

**Example Explanation**

Explanation 1:
```
3rd element after sorting is 2.
```

Explanation 2:
```
2nd element after sorting is 2.
```
